How I work

Build something you can try.
Leave enough evidence to explain it.

Start with the person using it

On a studio site the next step has to be clear. On the orchard site the same story needs to work in two languages.

Follow the failure

In a lab I compare what the service does, what the monitor sees and what the event history can prove.

Write down the result

I keep notes on what I changed, how I verified recovery and which checks still need to happen.

What I’m working toward
